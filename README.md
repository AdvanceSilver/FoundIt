🔍 FoundIt

FoundIt is an Android application designed to help people report, discover, and recover lost and found items.

Our goal is to make reconnecting people with their lost belongings easier through a simple, community-driven platform.

✨ Features

- 📝 Lost & Found Reports – Create reports for lost or found items.
- 🔎 Explore – Browse, search, and filter reports.
- 🗺️ Interactive Map – View reported item locations on a map.
- 📸 Photo Uploads – Add pictures to item reports.
- 💬 Private Chat – Communicate with other users.
- ✓✓ Read Receipts – Know when your messages have been read.
- 🔔 Notifications – Stay updated with app activity.
- 👤 User Profiles – Manage your personal profile.

📱 Compatibility

- Platform: Android
- Minimum Android version: Android 7.0 (API 24)
- Language: Kotlin
- UI: Native Android

🛠️ Technology Stack

- Kotlin
- Android SDK
- Supabase – Backend and database
- MapLibre – Interactive maps
- OpenStreetMap – Map data
- Glide – Image loading
- Kotlin Coroutines – Asynchronous operations

🚀 Installation

1. Open the "Releases" (../../releases) page.
2. Download the latest FoundIt APK.
3. Install the APK on your Android device.
4. Open FoundIt and get started.

🔐 Privacy & Security

FoundIt uses Supabase for backend services. User data and reports are handled through the application's backend configuration and database security policies.
